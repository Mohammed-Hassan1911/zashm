## MASTER STYLE BLOCK ( consistency )

Every image in this campaign must share the same DNA. Append this block to the end
of EVERY prompt so the five scenes look like one film:

```
STYLE: ultra-realistic 4K cinematic still, shot on 35mm film, subtle film grain, shallow depth of field, warm low-key lighting, deep soft shadows, sophisticated composition, luxurious production design, high-end European fashion editorial photography, quiet luxury, aristocratic heritage, timeless elegance, mysterious exclusive atmosphere.
PALETTE (strict): deep burgundy, antique ivory, dark chocolate brown, muted antique gold, warm shadows.
AVOID: flashy luxury clichés, excessive gold, modern technology, visible brand logos, generic clothing-commercial look, neon, clutter.
```

Aspect ratio flags per tool:
- **Midjourney:** add `--ar 9:16 --style raw --v 6.1` (or latest)
- **Firefly/Leonardo:** set aspect ratio to 9:16 in settings
- **DALL·E:** ask for "vertical 9:16" in the prompt

## TIMELINE & EDIT GUIDE (25s total)

| Time | Scene | Overlay text | Sound |
|---|---|---|---|
| 0–4s | 01 Arrival | `AN INVITATION HAS ARRIVED.` | clock + soft orchestra |
| 4–8s | 02 Seal | `PRIVATE & CONFIDENTIAL` | wax crack foley |
| 8–12s | 03 Invitation | `YOU ARE CORDIALLY INVITED.` | paper slide + strings |
| 12–18s | 04 World (A→B→C→D) | `A DIFFERENT STANDARD.` | door creak + footsteps |
| 18–25s | 05 Reveal | (in image) `ZASHM` / tagline / `COMING SOON.` | deep orchestral hit |

**Typography spec (overlays in CapCut/Canva):**
- Font: elegant uppercase serif (e.g. Cormorant Garamond, Playfair Display, EB Garamond)
- Colour: antique ivory `#F1E7D0` (or muted gold `#C9A84C` for accents)
- Letter-spacing: generous (200–400 tracking) — always uppercase
- Small fade-in (0.6s) + fade-out; never slides or bounces

**Consistency tricks:**
1. Generate all five scenes in one session with the same seed/character reference where the tool allows.
2. In Midjourney, reuse the same `--seed` across scenes after you like the first result.
3. If a tool supports image references, feed Scene 01 as a style reference for 02–04 (palette/light lock) — but keep subject prompts explicit.
